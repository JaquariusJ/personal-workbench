# Feature menus

Read this during requirements discovery. Select only the relevant group and offer 4–8 choices per turn. These are prompts for a non-technical user, not a promise to build every item.

## Universal core outcomes

Ask `这个工作台最想帮你做好哪些事？（可多选）`:

- `[ ] 看清今天最重要的事`
- `[ ] 管理待办和进度`
- `[ ] 记录、整理与快速查找信息`
- `[ ] 跟踪客户、项目或订单`
- `[ ] 管理收入、支出或预算`
- `[ ] 养成习惯、记录生活或学习`
- `[ ] 展示数据、趋势和复盘`
- `[ ] 其他（请补充）`

## Common modules

Offer only modules that support the selected outcomes:

| ID | User-facing option | Usually includes |
| --- | --- | --- |
| F01 | 今日重点 | 置顶目标、时间、完成按钮 |
| F02 | 待办清单 | 新建、勾选、截止日期、筛选 |
| F03 | 日历与日程 | 日期视图、安排、提醒占位 |
| F04 | 项目看板 | 项目、阶段、下一步 |
| F05 | 客户/联系人 | 联系人、沟通记录、跟进日期 |
| F06 | 收入与支出 | 一笔记录、分类、本月汇总 |
| F07 | 资料库/笔记 | 记录、标签、搜索 |
| F08 | 目标与习惯 | 目标、每日打卡、连续天数 |
| F09 | 数据小报表 | 关键数字、简单趋势图 |
| F10 | 快速收集箱 | 一句话添加想法、任务或资料 |

## Scope and data menu

Ask separately after modules are chosen:

`第一版你想做到什么程度？（选一个）`

- `A. 最简可用：只做今天最重要的一件事和 1–2 个模块`
- `B. 常用版本：做选中的主要模块`
- `C. 完整版：全部选中模块；我会拆成几轮交付`

`数据希望在哪里保存？（选一个）`

- `A. 只在这台设备/浏览器保存，最快最简单`
- `B. 多台设备同步，需要小型服务器和数据库`
- `C. 和他人一起用，需要额外设计账号与权限`

## Example first reply

For “我想做一个摄影师工作台”, infer the goal, then offer:

`你最想先加入哪些模块？（可多选，直接回复编号，例如 F01、F04、F06）`

- `[ ] F01 今日拍摄与交付重点`
- `[ ] F02 修片/交付待办`
- `[ ] F04 拍摄项目进度`
- `[ ] F05 客户跟进`
- `[ ] F06 收入与回款`
- `[ ] F07 灵感和拍摄资料`
- `[ ] 其他（请补充）`
